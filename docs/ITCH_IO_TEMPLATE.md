# No Signal, Connect!

**No Signal, Connect!** adalah game **2D pixel-art puzzle-platformer** yang dibuat untuk **Gimersia Inspire 2026** dengan tema **Pulang** (*Gotong Royong*).

---

## Tentang Gim & Tema (Pulang)

Dua kakak-beradik — **Allen** (*Network Engineer*) dan **Luna** (*Programmer*) — terpisah saat dalam perjalanan pulang ketika Luna terjatuh ke area bawah tanah (*underground*) dan akses masuknya tertutup.

Satu-satunya cara mereka untuk bisa **pulang bersama** adalah saling membantu lintas dunia secara bergantian:
1. **Allen (Permukaan):** Menjelajahi kota, membuka peti *buff*, memecahkan puzzle jaringan (*Cable Sequence* & *Color Memory*), dan menyalakan **Menara Sinyal**.
2. **Luna (Underground):** Begitu sinyal aktif, layar berpindah ke Luna. Gunakan sinyal tersebut untuk membuka **Laptop** dan mengetik *command* serangan **kilatan petir** guna mengalahkan robot rusak & drone hingga mencapai **Pintu Keluar Stage**!

> **Aturan Penting:** Jika HP salah satu karakter habis, permainan berakhir (*Game Over*).

---

## Cara Bermain & Kontrol

| Aksi | Tombol | Keterangan |
| :--- | :--- | :--- |
| **Gerak Kiri / Kanan** | `A` / `D` atau `←` / `→` | Menggerakkan Allen atau Luna |
| **Lompat / Double Jump** | `Space` / `W` | Maksimal 2 kali lompatan berturut-turut |
| **Sprint** | `Shift` (Tahan) | Lari cepat menggunakan *Energy Bar* |
| **Interaksi / Buka Laptop** | `E` | Membuka peti, puzzle Menara Sinyal (Allen), atau Laptop (Luna) |
| **Kirim Command Serangan** | `Enter` | Menembakkan kilatan petir setelah mengetik command di laptop Luna |
| **Pause / Tutup Panel** | `Esc` | Membuka menu Pause atau menutup terminal/puzzle |

### Tutorial Singkat
- **Di Permukaan (Allen):** Ikuti petunjuk di awal stage, kumpulkan *buff* dari peti bila beruntung, lalu dekati **Menara Sinyal** dan tekan `E` untuk menyelesaikan puzzle.
- **Di Underground (Luna):** Saat sinyal aktif, tekan `E` untuk memunculkan laptop, ketik *command* persis seperti yang tertulis di layar (contoh: `sudo zap`), lalu tekan `Enter` untuk menembakkan petir ke arah musuh!

## Cara Menjalankan (How to Run)

- **Browser (WebGL):** Langsung klik tombol **Run Game** di halaman ini. *(Disarankan klik layar game sekali agar input keyboard aktif.)*
- **Windows:** Unduh file `.zip`, ekstrak seluruh folder, lalu jalankan `NoSignalConnect.exe` (atau gunakan file `Setup.exe`).

---

## Fitur Utama
- **Dual-World Alternating Gameplay:** Dua dunia terpisah (Permukaan & Underground) dalam satu misi yang saling bergantung.
- **Network Puzzles:** Puzzle sambung kabel (*Stage 1*) dan *Color Memory* (*Stage 2*).
- **Typing Combat:** Mekanik serangan unik berbasis ketik command terminal untuk Luna.
- **Buff & Power-Up:** *Heal*, *Energy Boost*, *Shield*, dan *ATK x2* dari peti maupun drop musuh.
- **2 Stage Lengkap + Intro & Outro Cutscene.**
